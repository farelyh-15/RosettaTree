Graf terhubung tanpa sirkuit. Pada pohon biner, simpul maksimal memiliki 2 anak (Kiri untuk bit 0, Kanan untuk bit 1).

🏷️

Syarat Mutlak Kode Awalan

Tidak boleh ada satu pun kode yang menjadi awalan (prefix) bagi kode lainnya. Ini menjamin data dapat didekodekan secara unik.

✅ Valid (Prefix Code)

Contoh: A=0, B=10, C=110. Pesan dibaca berurutan tanpa ambiguitas.

❌ Tidak Valid

Contoh: A=1, C=10. Salah karena A (1) adalah awalan dari C (10).
