Graf terhubung tanpa sirkuit. Pada pohon biner, simpul maksimal memiliki 2 anak (Kiri untuk bit 0, Kanan untuk bit 1).

🏷️

Syarat Mutlak Kode Awalan

Tidak boleh ada satu pun kode yang menjadi awalan (prefix) bagi kode lainnya. Ini menjamin data dapat didekodekan secara unik dan aman oleh komputer.

✅ Valid (Prefix Code)

Contoh: A=0, B=10, C=110. Pesan dapat langsung dibaca berurutan dari depan tanpa ambiguitas komputer.

❌ Tidak Valid

Contoh: A=1, C=10. Mengandung ambiguitas tinggi karena kode A (1) merupakan struktur awalan dari kode C (10).
